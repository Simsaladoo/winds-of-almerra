# Download the Demo

Almerra's demo is now live on Itch.io!  The demo includes the character creator which is still receiving many needed updates, a tutorial sandbox level, and the Arena! 

### Character Creator
From the main menu you can select "New" to begin creating your character.  There are still many features missing and will still be receiving regular updates in the near future, but will be barebones initially.  It is not required to create a character to play the tutorial or arena, but will customize your experience if it is completed.

### Tutorial
The Tutorial level features a functional Quest system, with NPCs, Boats, Horses and items all being interactable.  This level is included as a testbed for fine tuning player controls, camera movements, dialogue with NPCs, using the inventory system, and many other parts of the gameplay.   

### Arena
The Arena is included to test AI combat.  You can select various weaponry within the armory before being sent into the fighting pit.  There you will have 25 enemies to fight against before being declared the winner.
